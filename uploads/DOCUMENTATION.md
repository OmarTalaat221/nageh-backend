# 🚀 التوثيق الشامل لمنصة ناجح (Najeh Platform API)

الوثيقة دي مكتوبة عشان أي حد لسه مبتدئ ومش عارف حاجة عن المشروع يقدر يفهم كل حاجة من غير ما يتوه. هنشرح كل جزء بالتفصيل: إيه الغرض منه، وإزاي تستخدمه، وإيه الداتا اللي المفروض تبعتها وترجعلك.

**الرابط الأساسي (Base URL) لكل الطلبات:**
```
https://camp-coding.online/najeh
```
يعني أي مسار (path) هتشوفه في الوثيقة زي `/admin/students` معناه الرابط الكامل بيبقى:
`https://camp-coding.online/najeh/admin/students`

**إزاي تبعت أي طلب محتاج تسجيل دخول؟**
بعد ما تعمل تسجيل دخول (Login)، هيرجعلك `access_token`. أي طلب بعد كده لازم تحطه في الـ Header بالشكل ده:
```
Authorization: Bearer {التوكين اللي رجعلك}
```
لو التوكين انتهت صلاحيته، فيه endpoint اسمه `refresh` بيديك توكين جديد من غير ما تعمل login تاني.

**اللغة**: أي طلب ممكن تحدد اللغة اللي عايز الرد يرجعلك بيها عن طريق الهيدر:
```
Accept-Language: ar   (أو en)
```

## 👨‍🎓 القسم الأول: الطالب (Student)

الطالب هو المستخدم اللي بيدرس ويتفرج على الكورسات، يحل امتحانات، يسلّم واجبات، ويحجز استشارات مع المدرسين.

### 1.1 تسجيل حساب جديد ودخول

| الطلب | الوصف بالتفصيل |
| :--- | :--- |
| `POST /user/student/auth/register` | تسجيل حساب طالب جديد. لازم تبعت: `name`, `email`, `password`, `phone`, `age`, `school_id`, `city_id`، وممكن تبعت `image` (رابط صورة شخصية) اختياري. بعد التسجيل الحساب بيبقى موجود بس **غير مفعّل** لحد ما يأكد إيميله. |
| `POST /user/student/auth/verify-email` | تأكيد الإيميل. بتبعت `email` و `code` (كود مكوّن من 6 أرقام اتبعت على الإيميل وقت التسجيل). |
| `POST /user/student/auth/resend-otp` | لو الكود ضاع أو انتهت صلاحيته، تقدر تطلب واحد جديد. بتبعت `email` بس. |
| `POST /user/student/auth/login` | تسجيل الدخول. بتبعت `email` و `password`. لو الإيميل مش متأكد هيرجعلك خطأ يقولك أكد إيميلك الأول. لو نجح هيرجعلك `access_token` و `refresh_token`. |
| `POST /user/student/auth/refresh` | تجديد التوكين لما ينتهي. بتبعت `refresh_token`. |
| `GET /user/student/auth/profile` | عرض بيانات البروفايل الخاصة بيك (محتاج تسجيل دخول). |

### 1.2 نسيت كلمة المرور (3 خطوات)

| الطلب | الوصف |
| :--- | :--- |
| `POST /user/student/auth/forgot-password` | تبعت `email` بس، وهيتبعتلك كود على الإيميل. |
| `POST /user/student/auth/verify-reset-code` | تبعت `email` و `code` عشان تتأكد إن الكود صح. |
| `POST /user/student/auth/reset-password` | تبعت `email`, `code`, `new_password` عشان تغيّر الباسورد فعليًا. |

### 1.3 الصفحة الرئيسية (Home)

| الطلب | الوصف |
| :--- | :--- |
| `GET /student/home` | ده أهم endpoint للطالب — بيرجعلك في طلب واحد: نسبة تقدمك العامة `overall_progress`، عدد اشتراكاتك، عدد شهاداتك، عدد الكتب المتاحة، الإشعارات، البانرات الإعلانية، كل الكورسات المتاحة (وموضح فيها إيه اللي أنت مشترك فيه)، **و `today_sessions`: كل حصص النهاردة اللي تخصك** (حسب اشتراكك في مادة كاملة أو كورس معين — واحد بس مش الاتنين مع بعض)، وكل حصة فيها `is_available_now: 1` لو الحصة شغالة دلوقتي فعلًا أو `0` لو لسه مجاش وقتها أو خلصت. |

> ℹ️ **ملحوظة عن التوقيت**: أي حساب لـ"دلوقتي" أو "النهاردة" في المنصة (زي `is_available_now` والحصص) بيفترض إن التوقيت هو **توقيت القاهرة (Africa/Cairo)** طول الوقت، إلا لو انت بعت `_time_zone` في الطلب (كـ query parameter في GET، أو field في الـ body في POST) بمنطقة زمنية تانية.

### 1.4 تصفح المحتوى التعليمي (كورسات / وحدات / فيديوهات / كتب)

| الطلب | الوصف |
| :--- | :--- |
| `GET /student/courses` | تصفح كل الكورسات المتاحة (بالفلاتر: مادة، سنة دراسية، قسم، بحث). |
| `GET /student/courses/show?id=` | تفاصيل كورس واحد. |
| `GET /student/course-details?id=` | تفاصيل موسعة للكورس (الوحدات والمحتوى اللي جواه). |
| `GET /student/my-courses-progress` | كورساتك المشترك فيها بس، مع نسبة تقدمك في كل واحد وعدد الدروس المكتملة. |
| `GET /student/my-subscribed-courses` | كل الكورسات المتاحة ليك بسبب اشتراكك (سواء اشتراك مباشر بالكورس، أو بالمادة، أو بالمدرس). |
| `GET /student/my-subscribed-subjects` | كل المواد الدراسية المتاحة ليك. |
| `GET /student/my-subscribed-teachers` | كل المدرسين المشترك معاهم. |
| `GET /student/books` | تصفح الكتب المتاحة. |
| `GET /student/my-subscribed-books` | الكتب المتاحة ليك حسب اشتراكك بس. |
| `POST /student/books/track-open` | تسجيل إنك فتحت كتاب معين، بتبعت `book_id`, `last_page_number`, `total_pages` — عشان المنصة تعرف تكمّلك من نفس الصفحة تاني مرة. |
| `POST /student/videos/track-progress` | تسجيل تقدمك في مشاهدة فيديو، بتبعت `video_id`, `watched_seconds`, `total_seconds`, `last_position_seconds`, `is_completed`. |
| `POST /student/courses/rate` | تقييم كورس بعد ما تخلصه (نجوم + تعليق). |
| `POST /student/teachers/rate` | تقييم مدرس. |

### 1.5 الامتحانات (حل الامتحان والنتيجة)

| الطلب | الوصف بالتفصيل |
| :--- | :--- |
| `GET /student/exams` | بيرجعلك كل الامتحانات المتاحة ليك **حسب اشتراكك بس** (امتحان على مادة كاملة يظهر لو انت مشترك في المادة، وامتحان على كورس معين يظهر لو انت مشترك في الكورس ده تحديدًا). كل امتحان فيه `my_attempt` يوضحلك لو أنت بدأته/سلمته قبل كده ودرجتك لو خلصت. |
| `POST /student/exams/start` | بداية حل الامتحان. تبعت `exam_id`، وهيرجعلك كل الأسئلة (من غير ما يوريك الإجابة الصح طبعًا) و `attempt_id` لازم تحفظه عشان تستخدمه وقت التسليم. |
| `POST /student/exams/submit` | تسليم إجاباتك. تبعت `attempt_id` ومصفوفة `answers` فيها لكل سؤال: `question_id` + حسب نوع السؤال (`mcq_option_id` للاختيار من متعدد، أو `true_false_answer` لصح/خطأ، أو `written_answer_text` للمقالي). **أسئلة الاختيار من متعدد وصح/خطأ بتتصحح أوتوماتيك فورًا**، أما الأسئلة المقالية فبتفضل معلّقة لحد ما المدرس أو الأدمن يشوفها ويحطلها درجة يدويًا. |
| `GET /student/exams/results` | كل نتايجك في كل الامتحانات اللي سلمتها. |
| `GET /student/exams/results/show?id=` | تفاصيل نتيجة امتحان واحد بالظبط — درجتك في كل سؤال، والإجابة الصح لو حابب تراجع نفسك. |

### 1.6 الواجبات (Homework)

| الطلب | الوصف |
| :--- | :--- |
| `GET /student/homework` | كل الواجبات اللي مدرسينك حطوها في المواد اللي انت مشترك فيها. كل واجب فيه `my_submission` يوضحلك لو انت سلمته قبل كده وإيه حالة الفيدباك (`submitted` يعني لسه المدرس مشافوش، `reviewed` يعني المدرس شافه وحطلك فيدباك). |
| `POST /student/homework/submit` | تسليم حل الواجب. تبعت `homework_id` و `file` (رابط أو رفع ملف الحل بتاعك). |

### 1.7 الاستشارات (Consultations)

| الطلب | الوصف |
| :--- | :--- |
| `GET /student/consultations` | المواعيد المتاحة اللي المدرسين حاطينها للاستشارة (ممكن تفلتر بـ `teacher_id` أو `subject_id`). |
| `POST /student/consultations/book` | حجز ميعاد. تبعت `slot_id` بس. لو حد سبقك وحجزه هيرجعلك رسالة إن الميعاد ده مبقاش متاح. |

### 1.8 الحصص (Sessions)

| الطلب | الوصف |
| :--- | :--- |
| `GET /student/sessions/today` | حصص النهاردة بتاعتك بس (نفس البيانات اللي بترجع جوه `student/home` لكن كـ endpoint منفصل لو محتاجها لوحدها). |

### 1.9 الاشتراكات والشهادات

| الطلب | الوصف |
| :--- | :--- |
| `POST /student/subscriptions/redeem-code` | تفعيل كود اشتراك اشتريته (14 رقم). تبعت `code`. الكود بيشتغل **مرة واحدة بس**، وبيفتحلك المواد/الكورسات/المدرسين اللي الكود مرتبط بيهم. |
| `GET /student/subscriptions/my-subscriptions` | قائمة كل اشتراكاتك الحالية. |
| `GET /student/my-certificates` | شهاداتك الصادرة + الشهادات المتاحة ليك حسب سنتك الدراسية واشتراكك. |

## 👨‍👩‍👦 القسم الثاني: ولي الأمر (Parent)

ولي الأمر بيقدر يتابع بس، مش بيضيف أو يعدل حاجة — دوره إنه يشوف حالة أبنائه المرتبطين بحسابه (والربط ده بيتم من الأدمن بس، مش ولي الأمر نفسه).

| الطلب | الوصف بالتفصيل |
| :--- | :--- |
| `POST /user/parent/auth/register` | تسجيل حساب ولي أمر جديد: `name`, `email`, `password`, `city_id`, `image` (اختياري). |
| `POST /user/parent/auth/verify-email` | تأكيد الإيميل بالكود اللي وصلك. |
| `POST /user/parent/auth/resend-otp` | إعادة إرسال كود التأكيد. |
| `POST /user/parent/auth/login` | تسجيل الدخول: `email` + `password`. |
| `POST /user/parent/auth/refresh` | تجديد التوكين. |
| `POST /user/parent/auth/forgot-password` | طلب كود إعادة تعيين كلمة المرور. |
| `POST /user/parent/auth/verify-reset-code` | التأكد من صحة الكود. |
| `POST /user/parent/auth/reset-password` | تعيين كلمة مرور جديدة. |
| `GET /user/parent/auth/profile` | **أهم endpoint لولي الأمر** — بيرجعلك بياناتك أنت + قائمة كل أبنائك (الطلاب) اللي الأدمن ربطهم بحسابك، مع تفاصيل كل واحد منهم. |

> ℹ️ ولي الأمر معندوش endpoints تانية غير كده — ربط/فك ربط الأبناء بيتم من لوحة الأدمن بس (`/admin/parents/link-student` و `/admin/parents/unlink-student`)، عشان محدش يقدر "يربط نفسه" بطالب مش ابنه.

## 🛡️ القسم الثالث: الأدمن (Admin)

الأدمن هو صاحب التحكم الكامل في المنصة. عنده صلاحية يضيف/يعدل/يمسح أي حاجة.

### 3.1 الدخول والصلاحيات

| الطلب | الوصف |
| :--- | :--- |
| `POST /admin/auth/login` | تسجيل دخول الأدمن: `email` + `password`. |
| `POST /admin/auth/refresh` | تجديد التوكين. |
| `GET /admin/auth/profile` | بيانات البروفايل. |
| `GET /admin/dashboard/statistics` | إحصائيات شاملة عن المنصة (عدد الطلاب، المعلمين، الكورسات، إلخ) — بتتعرض في الصفحة الرئيسية للوحة التحكم. |
| `GET /admin/roles` + `POST` + `PUT` + `DELETE` | إدارة **الرولز** (الأدوار) — كل رول ليه اسم وصلاحيات معينة. |
| `GET /admin/permissions` | قائمة كل الصلاحيات المتاحة في النظام (عشان تختار منها لما تعمل رول جديد). |
| CRUD `/admin/admins` | إدارة حسابات المسؤولين التانيين (كل واحد بيتحدد له رول). |

### 3.2 إدارة المستخدمين

| الطلب | الوصف |
| :--- | :--- |
| CRUD `/admin/students` | إضافة/تعديل/حذف/عرض الطلاب. لما الأدمن يضيف طالب بيبقى **مفعّل تلقائيًا** من غير ما يحتاج تأكيد إيميل. |
| CRUD `/admin/teachers` | نفس الفكرة للمعلمين، وبرضو بيقدر "يوافق" على معلم اتسجل بنفسه (`is_active`) و"يأكد" إيميله يدويًا (`is_email_verified`). |
| CRUD `/admin/parents` | نفس الفكرة لأولياء الأمور. |
| `POST /admin/parents/link-student` | ربط طالب بولي أمر: `parent_email` + `student_email`. |
| `POST /admin/parents/unlink-student` | فك الربط: `parent_id` + `student_id`. |

### 3.3 البيانات الأساسية (Lookups)

كل واحدة من دول عندها نفس النمط: `GET` (list) + `GET .../show?id=` (واحد بالتفصيل) + `POST` (إضافة) + `PUT` (تعديل) + `DELETE` (حذف). كل عنصر بيتكتب بالعربي والإنجليزي مع بعض (`name_ar`, `name_en`).

- `/admin/cities` — المدن.
- `/admin/subjects` — المواد الدراسية، وفيها كمان `link-academic-year` / `unlink-academic-year` لربط المادة بسنين دراسية معينة.
- `/admin/school-types` — أنواع المدارس (حكومي/خاص/دولي...).
- `/admin/schools` — المدارس.
- `/admin/academic-years` — السنوات الدراسية (أولى ثانوي، تانية ثانوي...).
- `/admin/course-categories` — أقسام الكورسات.
- `/admin/languages` — اللغات المتاحة في المنصة.

### 3.4 المحتوى التعليمي (كورسات، وحدات، فيديوهات، كتب، امتحانات، أسئلة)

المنطق العام: **الكورس** بيتقسم لـ **وحدات (Units)**، وكل وحدة جواها **فيديوهات + كتب + امتحانات**. وكل امتحان جواه **أسئلة**.

| الطلب | الوصف |
| :--- | :--- |
| CRUD `/admin/courses` | إدارة الكورسات (اسم، مادة، سعر، صورة، المعلمين المسؤولين). |
| `POST /admin/courses/link-teacher` / `unlink-teacher` | إضافة/إزالة معلم من كورس معين. |
| `POST /admin/courses/seed` | زرع بيانات تجريبية للاختبار (مش للاستخدام الفعلي). |
| CRUD `/admin/units` | الوحدات — لازم تتربط بكورس ومادة. |
| CRUD `/admin/videos` | الفيديوهات — بتتربط بوحدة (أو مادة/كورس مباشرة لو من غير وحدة). |
| CRUD `/admin/books` | الكتب/الملفات (PDF) — رابط أو رفع ملف فعلي. |
| CRUD `/admin/exams` | الامتحانات — بيها `duration_minutes` (مدة الامتحان بالدقايق)، `total_marks` (الدرجة الكلية)، `pass_marks` (درجة النجاح). |
| CRUD `/admin/questions` | أسئلة الامتحانات — 3 أنواع: `mcq` (اختيار من متعدد)، `true_false` (صح/خطأ)، `written` (مقالي). **مهم**: بعد ما تضيف السؤال وإجاباته، مش هتقدر تعدل الإجابات تاني (بس تقدر تعدل نص السؤال والدرجة والحالة) — لو غلطت في الإجابة الصح لازم تمسح السؤال وتضيفه تاني. |

### 3.5 نتايج الامتحانات (تصحيح المقالي)

| الطلب | الوصف |
| :--- | :--- |
| `GET /admin/exams/attempts?exam_id=` | كل محاولات الطلاب في امتحان معين — مين حل، ومين لسه، ودرجة كل واحد. |
| `GET /admin/exams/attempts/show?id=` | تفاصيل محاولة طالب واحد بالكامل — كل إجاباته سؤال سؤال. |
| `PUT /admin/exams/attempts` | تصحيح الأسئلة المقالية (اللي محتاجة عين بشرية). تبعت `attempt_id` ومصفوفة `answers` فيها لكل سؤال `question_id` + `score_awarded` (الدرجة اللي هتدّيها) + `teacher_note` (ملاحظة اختيارية). الدرجة الكلية بتتحسب تلقائيًا بعد كده. |

### 3.6 الشهادات والبانرات

| الطلب | الوصف |
| :--- | :--- |
| CRUD `/admin/certificates` | الشهادات اللي بتتدي للطلاب لما يوصلوا لدرجة معينة. |
| CRUD `/admin/banners` | البانرات الإعلانية اللي بتظهر في التطبيق. |
| `GET /admin/banners/views` | سجل مين شاف كل بانر وامتى. |

### 3.7 الاشتراكات وأكواد التفعيل

| الطلب | الوصف |
| :--- | :--- |
| CRUD `/admin/subscription-codes` | إنشاء أكواد اشتراك (14 رقم) يشتريها الطالب ويفعّلها. كل كود بيتربط بمادة/معلم/كورس معين، وليه سعر ومدة صلاحية وعدد استخدام. تقدر تولّد أكواد كتير مرة واحدة عن طريق `batch_count`. |
| `GET /admin/subscriptions` | كل اشتراكات الطلاب المفعّلة حاليًا. |
| `POST /admin/subscriptions` | منح اشتراك يدوي لطالب من غير ما يستخدم كود (`student_id` + مادة/معلم/كورس + مدة). |

### 3.8 الحصص وطلبات تغيير الميعاد

| الطلب | الوصف |
| :--- | :--- |
| `GET /admin/reschedule-requests?status=pending` | طلبات المعلمين لتغيير ميعاد حصة (لسه معلقة لحد ما الأدمن يوافق أو يرفض). |
| `PUT /admin/reschedule-requests` | الموافقة أو الرفض: `id` + `decision` (`approved` أو `rejected`) + `admin_note` اختياري. لو وافقت، ميعاد الحصة بيتغيّر فعليًا أوتوماتيك. |

## 👨‍🏫 القسم الرابع: المعلم (Teacher)

المعلم عنده صلاحيات شبه الأدمن لكن **مقصورة على المحتوى بتاعه هو بس** — أي حاجة يضيفها بتتسجل باسمه تلقائيًا، وأي قايمة يشوفها بترجعله بس المحتوى بتاعه.

### 4.1 التسجيل والدخول

| الطلب | الوصف |
| :--- | :--- |
| `POST /teacher/auth/register` | تسجيل حساب معلم: `name`, `email`, `password`, `subject_ids` (تقدر تسجل بأكتر من مادة), `city_id`, `whatsapp`, `specialization`, `image` اختياري. الحساب بيفضل **معلّق لحد ما**: (1) يأكد إيميله، **و** (2) الأدمن يوافق عليه. |
| `POST /teacher/auth/verify-email` | تأكيد الإيميل بالكود. |
| `POST /teacher/auth/resend-otp` | إعادة إرسال الكود. |

## 📌 ملاحظات عامة مهمة لأي مبتدئ

1. **كل رد من السيرفر بيرجع بنفس الشكل**: `{ "status": "success" أو "error", "message": "...", "data": {...} }`. لو `status` = `error`، يبقى فيه مشكلة والرسالة هتوضحلك إيه هي.
2. **الـ Pagination**: أي endpoint بيرجع قائمة طويلة (زي قايمة الطلاب أو الكورسات) بيقبل `page` و `limit` كـ query parameters، وبيرجع معاه `pagination` object فيه `current_page`, `total_pages`, `total_records`.
3. **الصور والملفات**: أي حقل زي `image` أو `file` بتقدر تبعته بطريقتين: (أ) رابط نصي جاهز (`https://...`)، أو (ب) ترفع الملف نفسه (multipart/form-data). الاتنين شغالين.
4. **الفرق بين `admin/*` و `teacher/*` لنفس المحتوى**: دايمًا نفس الشكل تقريبًا، الفرق إن الأدمن بيشوف/يتحكم في **كل حاجة**، والمعلم بيشوف/يتحكم بس في **اللي هو عامله أو مربوط بيه**.
